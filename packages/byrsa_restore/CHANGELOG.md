# Changelog

## 0.1.0 — unreleased

- Classical restoration in pure Dart: paper-colour estimation, background
  division and contrast-limited adaptive equalisation. No model, no download,
  no native library.
- Model store that refuses an unpinned model and deletes one whose digest does
  not match.
- A pipeline that records a stage it could not run instead of failing the
  capture.

No timing figures are published, on any platform.
